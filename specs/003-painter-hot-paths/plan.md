# 003 — plan

## Approach

Seven bit-identical rewrites in `ink`, each found by profiling the Lynmouth paint and proven
on the arguments that paint passes in (research, 2026-10-27, in the scratchpad's `hot/`
folders; the diffs below were written there and are applied here as written, with the
corrections named). One encoder setting changes file bytes but not pixels, under a new ADR.
No `maps` or `letters` file changes; no public API changes; layering untouched.

The shared idea: the painter spends most of its time on pixels that hold nothing (2.5 % of
an ink pad is laid; about 20 % of a pigment layer is painted), on strided memory, and on
copies. Every rewrite keeps each pixel's float32 operations and their order, and every
generator is drawn exactly as before.

| # | Where | Rewrite | Saving per Lynmouth paint |
|---|---|---|---|
| R1 | `ink/pad.py` `ink_density` | evaluate the saturate-and-gate expressions only where `acc != 0` (guard: all pixels when `b.dry > 1`), scatter into zeros, then bleed over the full array as before | ~10 s |
| R2 | `ink/sheet.py`, `ink/pad.py` | `Sheet.paper_on(h, w)`: the bilinear grow of `paper` cached per shape on the sheet, read-only; `pad._grow` deleted | ~1.5 s |
| R3 | `ink/noise.py` `blur`/`_box1` | each pass fills a transposed, edge-padded buffer by slicing (no `np.pad`), runs the sequential sum as contiguous row adds, subtracts and divides in place; six passes alternate axes in the old order | ~7.5 s |
| R4 | `ink/noise.py` `value_noise`, `_value_noise_at`, `fbm` | interpolate along x once per lattice row, then gather rows (same per-pixel ops, output stays float64 as today); flat `take` gathers; in-place octave add | ~2.2 s |
| R5 | `ink/pigment.py` `km_rt`, `km_plate` | glaze only painted pixels (a zero-density pixel has r = 0, tr = 1 exactly); in-place buffers in the same order | ~3.3 s |
| R6 | `ink/raster.py` `fill_cov` | whole-ring vectorised edge crossings with one integer `np.add.at` per ring; supersample count by strided `uint16` sums, one float32 division | ~2.3 s |
| R7 | `ink/deposit.py` `deposit` | flat indices into flat views of the accumulators for `np.add.at` (same elements, same order) | ~0.6 s |
| W1 | `ink/io.py` `save_webp` | lossless opaque plates at `method=1, quality=40` instead of `method=5`: decoded pixels identical (an opaque image has no hidden pixels), files 0.2 to 1.6 % smaller. `save_alpha`/`save_rgba` stay at method 4: any other method changes the RGB stored under alpha 0 | ~2.1 s |

Measured together the research expected the Lynmouth paint to fall from about 52 s to
about 22 s; the PR records the real figure.

Rejected in research, not to be revisited here: `sinh`/`cosh` from one `exp`, `np.bincount`
for `np.add.at`, sliding-window sums, masked-sum statistics (all reorder float arithmetic);
`chamfer_distance` (no gain); sharing one `Sheet` between `paint` and `letter` (their
`gran_px` differ, and a cross-call cache is module state); the `fetch` loops (0.3 s wall,
the 2.7 s CodSpeed figure is its instruction-count simulation); `ink/tip.py`'s cumsums (a
follow-up note, not this diff).

## Test plan

Test-first per rewrite: the invariant test is written and run against the old code
(passes, since the old code holds the invariant), then the rewrite, then the gates.

Invariant tests (no pinned hash; small seeded inputs built in the test):
- R1: an accumulator laid in a patch gives density exactly 0.0 outside the patch, and
  inside equals the full-grid evaluation of the same expressions; a brush with `dry > 1`
  takes the full-grid path (a pixel outside the patch need not be 0).
- R2: `paper_on(h, w)` returns the same array object on a second call, is read-only, and
  equals a fresh bilinear grow of `paper`; a second shape gets its own entry.
- R3: `blur` of a constant field is that constant everywhere; a step field keeps its
  edge values at the far ends (edge padding); a field that varies along one axis only
  stays constant along the other; the input is not modified. (Not transposition
  symmetry: the passes run in a fixed axis order, so `blur(a.T)` sums in another order.)
- R4 (property): `value_noise` stays in [0, 1], consumes the generator exactly as one
  `random((gh, gw))` call does (state compared with a twin generator), and keeps its
  dtype.
- R5: a layer of zero density leaves the base bit-identical; a layer painted in a patch
  leaves the rest of the base bit-identical.
- R6: a ring and the same ring with its points reversed fill the same coverage; a ring
  wholly off the canvas fills nothing.
- R7: deposits into a plate's accumulators land at the same pixels as a hand-placed
  stamp of one sample (an existing-style unit check with a literal 2 by 2 expectation).
- W1: a lossless opaque plate decodes to exactly the pixels written. The RGBA plates'
  unchanged setting is pinned by the exact golden bytes of `pen.webp` and
  `labels-centreline.webp`, which W1 must not move.

Exactness evidence (one-off, recorded in the PR, scripts not committed): the research
capture scripts re-run against the branch: every captured call equal bit for bit.

Gates, in order:
1. `uv run pytest -n auto --dist loadgroup -m "not golden and not benchmark"` green after
   each rewrite.
2. Exact golden locally, `uv run pytest -m golden -n auto --dist loadgroup`, green after
   each rewrite (after W1, green once the opaque plates are re-pinned).
3. `prek run --all-files`, `ruff`, `ty`, `lint-imports`.
4. Before/after: `cProfile` of `paint_fixture` and of one place card (Skye, the slowest),
   wall time of the local golden run, `uv run pytest -m benchmark --benchmark-enable`.
5. CI: all checks green, CodSpeed `paint` falls, no benchmark regresses past CodSpeed's
   threshold.

Acceptance map: profiles → step 4 and the docs page; pixels exact → step 2 and the
untouched docs pins; byte change under an ADR → W1, ADR 0043, the re-pins; CodSpeed → step
5; bit-identical evidence → the PR; invariants → the tests above; docs, note, issue → the
last three files.

## Delegation

The diffs exist, so applying them is mechanical; it stays in the main context, one rewrite
per commit, so a golden failure names its rewrite. Exact golden runs go to background
shells. A fresh-context diff review against this plan runs before the PR. The plan-reviewer
gate runs now.

## File-ownership partition

One track, in this order (each a commit, each gated by steps 1 and 2): R5, R6, R7 (small,
independent), R3, R4 (noise), R2 then R1 (pad and sheet), W1 with the ADR and re-pins,
then docs. No concurrent work.

## Decisions

- W1 at `method=1, quality=40`: the research's sweep found methods 1 to 3 give identical
  bytes and quality 40 equals 50, at under half the time and slightly smaller files.
- R2's cache lives on the `Sheet` (one per paint), not in a module: no state outlives a
  call.
- No new pinned hashes (#86); invariants plus the exact golden run instead.
- The `fetch` speed-up is dropped: it is real wall time of about 0.3 s.
- Bit-identity was proven on this machine (AVX-512); CI's tolerance golden on Linux and
  macOS is the cross-check, and a macOS exact difference would be recorded as #86 already
  records the hash differences.
