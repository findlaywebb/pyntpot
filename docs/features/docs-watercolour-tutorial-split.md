# The watercolour tutorial could be split, and its explanation moved out

GitHub issue: [#TBD](https://github.com/findlaywebb/pyntpot/issues/TBD)

**What exists today.** `docs/tutorials/paint-a-watercolour.md` is one 722-line page with
seven rungs (stretch the paper, lay a wash, pull a brush, mix two pigments, take up the
pen, letter a name, compose the painting). Each rung mixes doing with explaining: why the
paper's tooth matters, how a pool forms, how glazing mixes, which belongs in Explanation.

**What the feature would add.** One page per rung, or a few, under a Watercolour tutorial
section, each doing only, with the explanation moved to or linked from
`docs/explanation/` (much of it is already in `how-the-wash-works.md` and
`the-hand-and-the-nib.md`).

**Possible shape.** The rung pages keep their scripts and images; the nav-derived reading
order and the `Next:` lines follow the nav with no test edit. Inbound links to the
page's anchors (the gallery, the reference pages, `README.md`) need repointing.

**Related.** #172 (tutorial paths and quotes).
