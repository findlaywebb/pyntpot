# Painting with Python

These pages use the same engine for pictures that are not maps: curves drawn with the pen, one motif repeated by mirror and rotation, fractals, layered hills with a lettered name, and a small vector drawing washed and inked. You need only the first tutorial behind you, [Paint a watercolour](../paint-a-watercolour.md).

- [Curves: a rose, a Lissajous figure and a spirograph drawn with the pen](curves.md)
- [Symmetry: one motif washed and inked, then repeated by mirror and rotation](symmetry.md)
- [Fractals: a Barnsley fern and an Apollonian gasket](fractals.md)
- [Pictures: layered hill washes and a lettered Derwentwater](pictures.md)
- [Vector drawing: a small drawing, its filled shapes washed and its strokes inked](vector-drawing.md)
